# Proba feladat 01 - Git gyakorlat

Ez egy proba-feladat, amivel a fork + pull request munkafolyamatot gyakoroljuk.

## Feladat

Lepes 1: Fork-old ezt a repot a sajat GitHub-fiokodba (jobb felul, Fork gomb).
Lepes 2: Klonozd le a sajat gepedre.
Lepes 3: Hozz letre egy valasz.txt fajlt, amiben leirod egy mondatban, mit tanultal ma az oran.
Lepes 4: Commitold es pusholjad a sajat fork-odba.
Lepes 5: Nyiss egy Pull Requestet ide, az eredeti repoba.

## Hatarido

A kovetkezo ora elejeig.
